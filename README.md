# Dev Toolbox

Des outils de développeur qui tournent entièrement dans le navigateur : aucune donnée ne quitte la page.

Le projet est développé par un pipeline d'agents. Leurs consignes, la pile et les commandes sont dans [AGENTS.md](AGENTS.md).

## En local

```bash
npm ci
npm run dev
```

Puis ouvrir http://localhost:3000.
